Apps Web · Desktop · Móvil

Comprender antes de actuar

Alter convierte los hechos on-chain en una situación comprensible, con la fuente de prueba y las acciones realmente disponibles. No hace falta dominar el vocabulario EVM para entender el resultado.

  • Prueba visible: El detalle de capacidades muestra la fuente on-chain utilizada por Alter.
  • Situación de la dirección: Los estados nueva, financiada, activa e inactiva resumen la actividad observada.
  • Historial verificado: La importación del historial saliente muestra su progreso y verifica las transacciones por RPC.

alter-cli · Modo Inspector Desktop

Endpoint RPC local e inspección automatizable

Trabaja directamente con JSON-RPC cuando lo necesites o utiliza los objetos de dominio que Alter ya ha modelado.

  • Endpoint RPC local: alter rpc serve enruta solicitudes HTTP hacia los endpoints configurados, con balanceo, supervisión de salud y conmutación.
  • Inspección con pruebas: address inspect vincula las capacidades detectadas con su fuente on-chain.
  • Automatización CLI: Las salidas JSON y en árbol se integran en scripts y flujos reproducibles.
Alcance actual: alter-cli · Alter Desktop · endpoint HTTP local, sin WebSocket ni servicio cloud/público

alter-mcp · Servidor para agentes IA

Conocimiento estructurado y verificable

Alter proporciona herramientas MCP tipadas y descubribles, con resultados vinculados a sus pruebas y límites explícitos.

  • Retrato verificable: address.inspect incluye la fuente de prueba de cada capacidad expuesta.
  • Resultado completo: address.concentration devuelve la lista completa de titulares detectados.
  • Contexto transaccional: transaction.inspect clasifica todas las direcciones implicadas en la transacción.
Disponible: alter-mcp. Aún no entregado: compra autónoma con criptoactivos y autonomía transaccional de extremo a extremo.
Configuración Cliente MCP (mcp.json)
{
  "mcpServers": {
    "alter": {
      "command": "alter-mcp",
      "args": []
    }
  }
}
Instrucciones para Agentes (System Prompt / llms.txt)

Privacidad por defecto

Sin rastreo ni analíticas: las solicitudes utilizan los accesos RPC que configuras, sin una base de datos de terceros obligatoria.

Prueba on-chain (verifícalo tú mismo)

Los hechos que fundamentan una clasificación se pueden leer directamente en la blockchain pública. Copia la dirección en Alter, luego ve a Etherscan o GnosisScan: verás los mismos datos básicos. Alter siempre distingue estas pruebas on-chain de las heurísticas de presentación que las complementan.
