Pour les opérateurs d'Agents IA

Donnez à votre assistant IA (Claude, Cursor, Windsurf) la capacité de lire la blockchain via le protocole MCP.

Cas d'usage :

  • Demander à votre IA d'analyser un portfolio.
  • Laisser l'agent lire les capacités réelles d'un contrat.
  • Automatiser vos recherches en langage naturel.
Configuration Client MCP (mcp.json)
{
  "mcpServers": {
    "alter": {
      "command": "alter-mcp",
      "args": []
    }
  }
}

Claude Desktop : utilisez le chemin absolu du binaire (ex. /opt/homebrew/bin/alter-mcp) — Guide de configuration MCP

Confidentialité d'abord

Aucun traqueur, aucune analytique, aucun intermédiaire : vos requêtes vont directement aux nœuds RPC publics.

Preuve on-chain (vérifiable par vous)

Chaque classification s'appuie uniquement sur des faits lisibles directement sur la blockchain publique. Copiez l'adresse dans Alter, puis allez sur Etherscan ou GnosisScan : vous verrez les mêmes informations de base.
