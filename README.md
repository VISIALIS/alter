# Alter

Multi-chain EVM address intelligence — explore, classify and understand any address on EVM-compatible blockchains.

## Access

- **Web app**: <https://app.alter-evm.com>
- **Homebrew (macOS & Linux)**:

  ```bash
  brew tap VISIALIS/alter
  brew install alter-cli       # CLI
  brew install alter-mcp       # MCP server (AI agents)
  brew install --cask alter    # Desktop app (macOS)
  ```

- **Direct downloads**: official binaries are published on this repository's [Releases](https://github.com/VISIALIS/alter/releases) page.

## About this repository

This repository hosts the public releases of Alter. Homebrew formulas and the cask live in [VISIALIS/homebrew-alter](https://github.com/VISIALIS/homebrew-alter).
