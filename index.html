Know what an address is before you touch it.

Alter identifies any EVM address — wallets, tokens, contracts — and backs every classification with on-chain evidence. The same engine drives a web app, a command-line tool, and an MCP server for AI agents.

Explore addresses, capabilities, and their connections, visually. No install.

Classify addresses from scripts, or let AI agents query on-chain facts through MCP.
